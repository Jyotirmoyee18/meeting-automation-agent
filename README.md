## 🚀 Overview

**Meeting Automation AI Agent** is an intelligent system designed to **automatically join meetings, transcribe conversations in real time, and generate structured summaries and action items**.

This project leverages modern AI capabilities to reduce manual note-taking, improve productivity, and ensure that key insights from meetings are never lost.

🎓 **This project is developed as a Final Year B.Tech Project (CSE).**

---

## ✨ Key Features

* 🎙️ **Live Meeting Transcription**
* 🧠 **AI-Generated Summaries**
* ✅ **Action Item Extraction**
* 📧 **Automated Email Draft Generation**
* 📊 **Structured Meeting Insights**
* ⚡ **Real-time Processing with AI Agents**

---

## ⚙️ Getting Started

### Prerequisites

* Node.js (v16 or higher recommended)
* npm or yarn

---

### 🔧 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone <your-repo-url>
   cd <your-project-folder>
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Configure Environment Variables**

   Create or update `.env.local` and add:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Run the development server**

   ```bash
   npm run dev
   ```

5. Open your browser at:

   ```
   http://localhost:3000
   ```

---

## 🧠 How It Works

1. The AI agent joins a meeting session
2. Captures and processes audio input
3. Converts speech → text using real-time transcription
4. Uses AI to:

   * Generate concise summaries
   * Extract action items
   * Draft follow-up emails
